# Светлый дом — интернет-магазин освещения

Многостраничный демонстрационный каталог осветительных приборов. Лабораторная работа: вёрстка на чистом HTML5 и CSS3, без JavaScript и без сборщиков.

Все товары, цены и контакты магазина вымышлены и не являются реальными.

## Демо

Откройте `index.html` в браузере — сборка и сервер не требуются.

## Возможности

- Адаптивная вёрстка: боковое меню, сетка карточек товаров и страница товара перестраиваются под ширину экрана (десктоп / планшет / телефон)
- Три раздела каталога: потолочные светильники, настенные светильники, настольные лампы — по 10 товаров в каждом
- Отдельная страница на каждый товар (30 страниц) со своими характеристиками и фотографией
- Информационные страницы: «О фирме» (реквизиты, график работы, карта проезда) и «Об авторе»
- Единый файл стилей на основе CSS-переменных: цвета, отступы и радиусы скругления настраиваются в одном месте

## Структура проекта

```
├── index.html                  главная страница
├── company.html                страница «О фирме»
├── author.html                 страница «Об авторе»
├── polotok_lamp-menu.html      каталог: потолочные светильники
├── stena-menu.html             каталог: настенные светильники
├── table-lamps-menu.html       каталог: настольные лампы
├── css/
│   └── style.css               общий файл стилей
├── images/
│   ├── header-banner.svg       баннер шапки
│   └── products/                фотографии товаров
└── products/
    ├── шаблон.html             заготовка страницы товара с комментариями
    └── *.html                  страницы отдельных товаров (30 файлов)
```

## Технологии

- HTML5 (семантические теги: `header`, `nav`, `main`, `footer`, `article`, `section`)
- CSS3: Flexbox, Grid, CSS-переменные, медиа-запросы

## Известные ограничения

Кнопка «Добавить в корзину» и мобильная кнопка «Меню» — статичная вёрстка без обработчиков: JavaScript в проекте не используется, поэтому переключение состояния не реализовано.
